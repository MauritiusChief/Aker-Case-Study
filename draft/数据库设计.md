# 加拿大 Aker 物业数据库

虽然只显示 As Of = 02/25/2026 和 Month Year = 02/2026, 但是我觉得还是需要考虑多个月份的情况的

residential_units 表
- unit_code (PK) TEXT
- property_code (PK)(FK) TEXT: 物业的代码
- type TEXT
- area INT: in feet², 未观察到小数
- market_rent REAL
- status TEXT: OCCUPIED / VACANT / MODEL / DOWN / ADMIN
- resident_id (FK) TEXT: 可为 NULL

residents 表
- id (PK) TEXT
- name TEXT
- security_deposit REAL
- other_deposit REAL
- balance REAL: 因为付款不会区分付了 rent roll 里的哪一项，只会算有多少钱没付，所以这样设计也合理
- move_in_date TEXT
- lease_end_date TEXT
- move_out_date TEXT: 可为 NULL
- unit_code (FK) TEXT: 可为 NULL
- property_code (FK) TEXT: 物业的代码, 可为 NULL

rent_rolls 表：目前只给了 02/2026 的数据，但我觉得还是需要考虑多月的情况的
- id (PK) INT
- month_year TEXT: 目前只有 02/2026
- charge_code TEXT
- amount REAL
- resident_id (FK) TEXT

Properties 表
- code (PK) TEXT: 物业的代码
- name TEXT
